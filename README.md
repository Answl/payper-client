## Getting Started

###  Requirements

| 항목         | 버전           |
|--------------|----------------|
| - Vue               | 3.5.17    |
| - TypeScript        | 5.8       |
| - Vite              | 7.0       |
| - Tailwind CSS      | 4.1.11    |
| - Pinia             | 3.0.3     |
| - Vue Router        | 4.5.1     |
| - Axios             | 1.10.0    |
| - Vitest            | 3.2.4     |
| - ESLint            | 9.29.0    |

---

###  Installation

```bash
$ git clone https://github.com/payper-devs/payper-client.git
$ cd payper-client
```
